# Contributing to nibi

Report fork-specific bugs or ideas in this repository. Include macOS version,
Apple Silicon model, nibi version, target editor, reproduction steps and
expected/actual behavior. Use invented sample phrases; do not attach private
recordings, dictionary files, transcripts, credentials or full app-data folders.

Keep patches focused. Preserve local-only processing and explicit confirmation
before a phrase is remembered. Add meaningful tests for changes to persistence,
matching or accessibility observation. Follow AGENTS.md for code conventions.
Run the focused checks in LOCAL_CORRECTIONS.md. Explain AI assistance honestly.

Use nibi's PR template for contributions to this repository. AI-assisted work and
contributor-authorized automated PR creation are welcome; disclose the tools and
scope of assistance. A separately human-written description is not required.

Handy's original CONTRIBUTING.md is retained for reference and changes proposed
upstream. Follow Handy's own templates and discuss new features there before
preparing a focused upstream contribution.
